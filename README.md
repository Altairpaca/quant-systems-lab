# Quant Systems Lab

Deterministic, evidence-first systems experiments for quantitative workloads. The first
experiment merges individually ordered feed events by the time at which they become available to
a consumer, and replays L2 price-level updates into observable book state, backed by independent
oracles, synthetic fixtures and controlled benchmark evidence.

**Scope statement:** synthetic and academic material only — no employer data, no trading
strategy, no credentials, no brokerage connector, no live trading. Nothing here is a claim about
exchange latency, profitability or production readiness.

**Status:** the implementation arrives through reviewed pull requests (conformance core, then the
book-state consumer, then the benchmark runner). Until a pull request is merged, this branch
contains only this scope statement, the license and the ignore rules.
